Assinatura: do clique ao limite liberado

1 · Clique em “Assinar”
POST /api/checkout cria Checkout Session mode=subscription
→
2 · Pagamento no Stripe
checkout hospedado; o app nunca vê dados de cartão
→
3 · Stripe emite eventos
subscription.created e checkout.session.completed
4 · POST /api/webhook
constructEvent valida o HMAC sobre o corpo bruto (STRIPE_WEBHOOK_SECRET)
→
5 · Plano no banco
UPDATE usuarios: premium=1, stripe_customer_id, stripe_subscription_id
→
6 · Limite liberado
a geração ignora a cota de usuário premium (201)

Cancelamento

A · Cancelamento
pela API do Stripe (sem portal do cliente)
→
B · Evento
customer.subscription.deleted
→
C · Webhook
mesma validação de assinatura
D · Plano no banco
UPDATE usuarios SET premium=0 por stripe_subscription_id
→
E · Limite volta
4ª geração do mês: 403 limite_gratuito_atingido
